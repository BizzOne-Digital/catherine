## Style Modifiers to Add (Optional)

For more consistent high-quality results, add these to any prompt:

**For Midjourney:**
- `--ar 16:10` (aspect ratio for treatment cards)
- `--style raw` (for more photographic results)
- `--v 6` (latest version)

**General Style Add-ons:**
- "shot on Canon EOS R5, 85mm lens, f/2.8"
- "professional medical photography"
- "soft box lighting, warm color grading"
- "luxury medical spa aesthetic"
- "editorial beauty photography style"
- "clean, elegant, sophisticated"

**Color Palette:**
- "warm beige, soft gold, ivory white tones"
- "medical spa color palette: beige #FAF4EB, gold #C4972F"
